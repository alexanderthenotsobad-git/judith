# Judith Mitchell — Portfolio

A vibrant, single-page React portfolio built around a soft pink + lavender palette.
It covers Judith's professional experience, education, certifications, and her
community work with the AWS Los Angeles user group and AISES.

## Run it locally

Requires Node.js 20.19+ (Node 22 recommended).

```bash
npm install
npm run dev
```

Vite prints a local URL (usually http://localhost:5173).

To build and preview the production bundle:

```bash
npm run build
npm run preview
```

A production build is already included in `dist/` (recreate it with
`npm run build`). The build uses a relative base path (`base: './'`), so it can be
served from a subfolder or dropped on any static host. (Open it through a server — `npm run
preview` — rather than double-clicking the file, since browsers block ES modules
loaded over `file://`.)

## Where to edit content

All copy lives in [`src/data/profile.js`](src/data/profile.js):

- `profile` — name, headline, intro, location, quote
- `stats` — the four headline numbers
- `skillGroups` — marquee terms and the "About" focus cards
- `experience` — roles, dates, bullets, skill tags
- `community` — AWS Builders LA / AWS Los Angeles user group content (intro,
  official "About the group" copy, logo, photos) and AISES content
- `education` / `certifications`
- `navItems` — section navigation

## Images

Source images are in `assets/images/` and are untouched. The site uses optimized
copies in `public/media/`, generated by:

```bash
npm run images
```

That script (Sharp) resizes the portraits and event photos, trims the 3M and AWS
marks into usable logo tiles, and crops the UCLA crest. Delete `public/media/` and
re-run the command if you change the source files.

## Structure

```
assets/images/        original supplied images
public/media/         optimized images used by the page
public/favicon.svg    JM monogram favicon
scripts/              image optimization script
src/
  components/         page sections + small UI primitives
  data/profile.js     all portfolio content
  styles/             tokens/base, components, sections
  App.jsx             page composition
  main.jsx            React entry point
```

## Notes

- **Connected apps** (Replit Agent) were left off: a LinkedIn "connected app" is a
  profile integration, not portfolio content, so it would read oddly to a visitor.
- The **AWS Builders LA** crest is used in the community feature card, alongside
  the group's official "About us" copy. Judith's LinkedIn URL is set to
  `https://www.linkedin.com/in/judith-mitchell/`.
- **AISES** is included as a subtopic rather than a headline: it appears in the
  Community section (with the organization's definition and the 2021 Professional
  Chapter of the Year award), in the experience timeline, in education highlights,
  and as a focus card.
- Experience bullets and dates follow the supplied LinkedIn material; light copy
  edits were made for web readability only.
- Motion respects `prefers-reduced-motion`, photos open in an accessible lightbox
  (Escape to close, focus trap), and the layout is responsive from 320px up.
